## 0. 한 줄 요약

## 2. 손익분기 산식 (재사용)

```
비용R          = 왕복 비용% ÷ 손절폭%
손익분기 승률   p* = (평균손실R + 비용R) ÷ (평균이익R + 평균손실R)
손익분기 PnL%   = 건당 평균 Gross PnL% > 왕복 비용%
```

| V4 실측 (W 1.40R / L 0.88R) | 비용 0 | A (0.066%) | B (0.105%) |

| 손익분기 승률 (평균값 산식) | 38.7% | 48.1% | 54.0% |

| 필요 Gross PnL%/건 | >0 | >0.066% | >0.105% |

## 3. 교훈 (원리)

### L1. 손익비 ≠ 엣지
무작위 보행에서 TP 선도달 확률 = L/(W+L) → 어떤 손익비든 Gross 0. 승률형/손익비형 선택은 맞교환일 뿐. **엣지 = 무작위 승률 대비 초과분**뿐이다.

### L2. 짧은 시간축의 비용은 고정 세금이 아니라 손절폭에 반비례
15m는 비용이 Gross 엣지의 수십 배. 필터·피처 추가로 극복 불가(최대 기대 개선 < 0.05R, 측정 불가 영역).

### L3. 실패한 코어 위에 필터를 쌓지 않는다
H1/H2/H6 모두 코어가 C0·고원 단계에서 걸렸고, 부품(E1~E8)을 쌓지 않았다. 쌓았다면 PBO·선택편향으로 가짜 양수가 나왔을 것.

### L4. 무작위 대조군(C0/C0-β)이 가장 강력한 진단
"양수인가"보다 "무작위보다 나은가"가 먼저. C0-β(드리프트 보정)가 없으면 2023-24 상승장 롱 편향을 엣지로 착각한다(H6 롱 +0.007 / 숏 −0.026).

### L5. 단조 개선 = argmax 유혹
H6 N=40만 양수. 격자 끝점으로 옮기면 argmax. 대신 **새 사전등록**(더 느린 시간축)으로 독립 검증해야 한다.

### L6. 측정 인프라부터 검증
라이브 채점기 버그(F9)는 하니스와 로그를 대조해서야 발견. 새 채점기는 라이브 기록과 건별 대조를 먼저 통과시킨다.

### L7. 검정력 한계는 실재
MDE 0.067~0.112R. 이보다 작은 엣지는 이 데이터로 배제도 확인도 불가. 4H로 가면 n이 1/4 → MDE ≈0.135R → **유니버스 확대 필수**.
