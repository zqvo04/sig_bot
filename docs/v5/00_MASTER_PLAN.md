## 0. 성공의 정의

- **최종 목표: 실전(실주문·실비용)에서 수익을 내는 V5 알고리즘.**
- 이를 위한 실험의 목적: 파라미터·파라미터 조작(섭동/dropout)·계산 방식·레이어(필터) 수 등 **설계 요소 하나하나를 가설로 세워 검증**하고, **과적합 없이 살아남는 요소만** 조립해 V5를 만든다(§4.5).
- 중간 판정 기준: **"비용 차감 후 CI 하한 > 0 인, 파라미터 ≤5개의 거친 엣지가 존재하는가"**. 실전 전환은 별도 게이트(Phase 6).
- **NO-GO도 정당한 성공 결과**다. 실전 돈을 잃지 않는 것이 엣지 없는 전략을 배포하는 것보다 낫다. 모든 트랙이 기각되면 그 근거를 보고하고 종료한다.
- 점추정·단일 구간·단일 심볼·단일 방향 결과로는 어떤 채택도 하지 않는다.

### 1.1 시나리오 A(낙관) 해석 규칙 — 사전 고정

A는 비용의 **하한(lower bound)**이다. 따라서 판정은 **비대칭**이다.

| A 결과 | 판정 | 이유 |
|---|---|---|
| Net R CI **상한 < 0** | **구조적 음수 확정 (강한 NO-GO)** | 가장 유리한 비용에서도 음수면 현실 비용에서는 더 나쁘다 |
| CI가 0 포함 | 보류(측정 불가) | 검정력 부족 또는 엣지 ≈ 0 |
| CI **하한 > 0** | **필요조건만 충족 — GO 근거 아님** | 메이커 체결 확실성·역선택을 무시했으므로, 시나리오 B/C 민감도를 *보조 출력*으로 반드시 병기 |

A의 숨은 낙관 가정(보고서에 매번 명시): ① 메이커 진입 100% 체결, ② 체결 역선택(adverse selection) 0, ③ SL 슬리피지 0, ④ 스프레드 0.5bp 고정.

### Phase 4 — 가설별 단일 변수 실험 + 설계 요소 조립
- 트랙 가설마다 **§4.5 빌드 루프**(E1~E8)로 V5 구성을 조립한다.
- 탐색 구간에서만 개발. 검증 구간은 사전등록 기준으로 **1회 판정**.

### Phase 5 — 봉인 holdout 1회 열람
- 진입 조건: Phase 4 채택 후보 존재 + **사용자 명시 승인**.
- 열람자는 메인 세션만. `LEDGER.md`에 시각·커밋 SHA·후보·결과를 기록. 재열람 금지(열람 후 변경 = 새 holdout 필요 = 사실상 라이브 Shadow 전진검증으로 대체).
- GO 조건: 4-게이트(counterfactual 필터링 · 구조 분절 · 워크포워드 · Bootstrap CI) + holdout Net CI 하한 > 0.
- GO 이후: `src/v5/` 구현, 기본 OFF, Shadow 전진 운영. 라이브 V4와 서로소.

### Phase 6 — 실전 전환 (최종 목표 게이트)
holdout 통과는 "과거에 엣지가 있었다"일 뿐이다. 실전 수익은 아래를 **순서대로** 통과해야 한다.

| 단계 | 내용 | 통과 기준 (사전 고정) |
|---|---|---|
| 6a 전진 가상 | `src/v5/` 신호를 실시간 가상 운영. 진입 시점의 **실제 호가·스프레드 실측**을 컬럼 저장 | 실측 비용 ≤ 백테스트 가정 비용, 신호 빈도가 백테스트의 ±30% 이내 |
| 6b 비용 재판정 | 6a 실측 비용으로 **시나리오 B 이상**(낙관 A 불가) 재채점 | Net CI 하한 > 0, n ≥ 사전 계산한 필요 n |
| 6c 체결 실측 | (메이커 사용 시) 지정가 미체결률·역선택 실측 | 미체결·역선택 반영 후에도 6b 유지 |
| 6d 소액 실주문 | **별도 사용자 결정 사항.** 현 코드는 실주문 없음 — 주문 모듈은 신규 설계·리뷰 필요 | 손실 한도(kill switch) 사전 고정, 전진 결과가 6b CI 안 |

- 6a~6c 중 하나라도 실패하면 실전 전환 금지. 원인을 장부에 기록하고 Phase 4로 회귀(새 가설 = k 증가).
- **실전 판정에 시나리오 A(낙관) 사용 금지.** A는 Phase 1의 "비용 하한" 판정 전용.

## 4. 실험 트랙 (여러 가능성 병행 고려)

Phase 1 결과에 따라 열리는 트랙이 다르다. **트랙 = 가설 묶음**이며 모든 시도는 장부 k에 산입된다.

| 트랙 | 질문 | 열리는 조건 | 성격 |
|---|---|---|---|
| **T1** 재채점 | 기존 V4는 비용 후 음수인가 | 항상 (Phase 1) | 확인 |
| **T2** 진입 정보량 | ORTHO 진입은 무작위 진입보다 나았는가 (동일 청산·비용) | 항상 (Phase 3 C0) | 확인 — 기존 설계의 사망 진단 |
| **T3** 손절폭 확대 | 동일 진입 철학을 1h/4h로 올리면 cost_R이 줄어 순엣지가 생기는가 | T1 = 구조적 음수 | 가설 (카탈로그 H1·H4) |
| **T4** 메이커 체결 | 지정가 진입으로 비용 구조를 바꿀 수 있는가 (역선택 측정 포함) | T1 = 구조적 음수 | 가설 (H2) |
| **T5** 펀딩/캐리 | 가격 방향 예측이 아닌 펀딩 극단·캐리 수취 | 항상 후보 | 가설 (H3) |
| **T0** 종료 | 모든 트랙 기각 → NO-GO 보고, 라이브는 측정용으로만 유지 | T2~T5 모두 기각 | 결론 |

결정 트리:
```
Phase 1 (A)
 ├─ 구조적 음수 → T2 진단 → T3·T4·T5 중 사용자 승인 가설 → Phase 3/4
 ├─ 보류(0 포함) → T2 진단 → 동일 (단, "기존 V4 계속 관찰" 옵션 추가)
 └─ 하한>0      → B/C 민감도 확인 → B에서도 하한>0 이면 기존 V4를 holdout 후보로 / 아니면 T3~T5
```

## 4.5 설계 요소 실험 프레임워크 (V5 조립 방식)

트랙(T3~T5)이 **"무엇을 거래하나"**라면, 설계 요소 실험은 **"그 전략을 어떤 부품으로 조립하나"**다. V5는 처음부터 완성형으로 설계하지 않는다. **최소 코어에서 시작해 부품을 하나씩 가설로 검증하며 쌓는다**(전진 선택, forward selection). 반대로 기존 ORTHO처럼 이미 큰 구조는 **하나씩 빼 본다**(후진 제거, ablation).

### 4.5.1 실험 유형 (E-시리즈)

| ID | 유형 | 질문 | 방법 | 채택 조건 (§4.5.3 공통 + 아래) |
|---|---|---|---|---|
| **E1** | 레이어 ablation (drop-one) | 이 레이어/필터/VETO는 기여하는가 | 전체 구성에서 **한 번에 하나씩 제거** → Net R 변화 ΔR 측정 | 제거 시 ΔR < 0 이고 CI가 0을 넘어야 "유지". 아니면 **삭제**(단순성 우선) |
| **E2** | 레이어 추가 (add-one) | 코어에 이 레이어를 더하면 나아지는가 | 코어 + 후보 1개. 거래 수 감소도 함께 보고 | ΔR CI 하한 > 0 **그리고** 거래 수 감소 후에도 MDE 충족 |
| **E3** | 레이어 수 / 복잡도 곡선 | 몇 개의 레이어가 적정한가 | 레이어 1·2·3…개 구성의 Net R(탐색 vs 검증)을 나란히. 과적합이면 탐색↑ 검증↓로 벌어짐 | **1-SE 규칙**: 최고 성능의 1 표준오차 안에 드는 **가장 단순한** 구성 채택 |
| **E4** | 파라미터 섭동 (perturbation) | 파라미터를 조금 흔들어도 엣지가 유지되는가 | 채택값의 모든 파라미터를 동시에 ±10%/±20% 무작위 섭동, 200회 → Net R 분포 | 섭동 분포의 **≥80%가 Net > 0** 이고 중앙값 ≥ 원값의 50%. 아니면 "칼날 위 파라미터" → 기각 |
| **E5** | 파라미터 dropout | 이 파라미터는 꼭 필요한가 | 파라미터 하나를 **경제적 기본값(사전 지정)으로 고정**하거나 해당 조건을 제거 → 성능 비교 | 고정해도 성능이 CI 안에서 같으면 **파라미터 삭제**(예산 반환) |
| **E6** | 계산 방식 변형 | 같은 개념을 어떻게 계산할까 | 사전 등록된 **소수(≤3) 범주형 선택지**: 예) 백분위 vs z-score vs ATR 비율, SMA vs EMA, 종가 vs VWAP 기준 | 선택지 간 차이가 CI 안이면 **가장 단순한 것**. 하나만 좋으면 스파이크 의심 → E4로 재검증 |
| **E7** | 청산 구조 변형 | TP/SL/시간/BE 중 무엇이 엣지를 살리나 | 동일 진입에 청산만 교체(고정 RR, ATR 배수, 시간 청산, BE 유무) | 진입과 분리해 평가(진입 효과와 혼동 금지) |
| **E8** | 데이터 섭동 (robustness) | 데이터 노이즈에 민감한가 | 진입 1봉 지연, 캔들 가격에 ±0.5틱 노이즈, 심볼 1개씩 제외(leave-one-symbol-out) | 모든 섭동에서 Net 점추정 > 0, 1봉 지연 시 붕괴하면 룩어헤드 의심 |

### 4.5.2 조립 절차 (V5 빌드 루프)

```
0. 코어 정의: 트랙 가설 1개의 최소 형태(파라미터 ≤2), 청산은 E7에서 사전 지정한 기본값
1. 코어 평가 (탐색 구간) → C0 무작위 대조군을 넘는가? 아니면 이 트랙 종료
2. 후보 부품 목록(사전등록, 부품마다 경제적 근거 1줄) 순서대로:
     E2 add-one → 통과 시 채택, 실패 시 폐기 (재시도 금지)
     채택할 때마다 파라미터 예산(≤5) 차감
3. 예산 소진 또는 후보 소진 → E1 ablation 으로 역검증(채택 부품 중 무임승차 제거)
4. E5 dropout 으로 파라미터 정리 → E4 섭동 · E8 데이터 섭동 으로 견고성 확인
5. E3 복잡도 곡선 + 1-SE 규칙으로 최종 구성 확정
6. 이 구성 1개만 검증 구간에서 1회 판정 → Phase 5 후보
```
- 기존 ORTHO 부품(L/F/S, 레짐 라우터, MACRO/FLOW/CROWD/TAKER VETO)은 **후보 부품 목록으로 재활용 가능**하다. 단, 각각 E2를 처음부터 다시 통과해야 한다(V3/V4 성과는 근거 아님).

### 4.5.3 모든 E-실험 공통 조건
- **탐색 구간에서만** 수행. 검증 구간은 4.5.2 의 6번에서 최종 구성 1개에 대해서만 연다.
- 한 실험 = 한 변수(단일 변경). E4는 예외(견고성 측정이지 선택이 아님 — 결과로 값을 바꾸지 않는다).
- 롱/숏 **동시 적용**(미러 부품). 한 방향에서만 효과 → 기각.
- 모든 비교는 **비용 차감 후 Net R** 기준.
- 각 E-실험은 장부에 1건으로 산입하고 §5.6 의 계층 구조로 유의성 판정.

## 5. 통계 프로토콜 (전 단계 공통)

### 5.1 신뢰구간
- 기대값: Bootstrap 퍼센타일 CI(`ortho_report.bootstrap_ci`, seed 고정) **+ 일 단위 블록 부트스트랩**(크립토 동조화로 같은 날 신호는 독립 아님). 둘 중 **넓은 쪽**으로 판정.
- 승률: Wilson CI. 손익분기 승률 = |avg loss| / (avg win + |avg loss|) 병기.
- 신뢰수준: 1 − 0.05/k (k = 장부 누적 가설 수).

### 5.2 검정력 (σ = 1.24R 실측, 검정력 80%, 양측)

| 엣지 μ (R) | α=0.05 | α=0.01 | α=0.005 |
|---|---|---|---|
| 0.05 | 4,827 | 7,183 | 8,188 |
| 0.10 | 1,207 | 1,796 | 2,047 |
| 0.15 | 536 | 798 | 910 |
| 0.20 | 302 | 449 | 512 |
| 0.30 | 134 | 200 | 227 |

- 블록 상관으로 유효 n은 이보다 작다 → 각 가설의 **MDE는 탐색 구간 예상 거래 수 기준으로 계산**하고, MDE > 0.10R 이면 "측정 불가".
- 시사점: **15분봉에서 μ≈0.05R 엣지는 원리상 검증 불가**. 상위 TF로 R을 키우는 것(T3)은 비용뿐 아니라 검정력 측면에서도 필요.

### 5.3 반응 곡선·고원(plateau) 규칙 — argmax 금지
- 각 파라미터는 **사전 격자 3~5점**만. 격자는 경제적 근거로 정하고 데이터 열람 전 커밋.
- 채택점은 **격자 중앙값(사전 지정)**. 최적점을 고르지 않는다.
- 고원 조건: 중앙값의 **양쪽 이웃 격자점 모두** Net 점추정 > 0 이고 중앙값 점추정의 ≥50%. 하나라도 위반 = 스파이크 → 기각.
- 2개 이상 파라미터를 동시에 바꾸지 않는다(한 번에 하나, `CLAUDE.md` §5).

### 5.4 데이터 분할 (Q2)
- 시간순 **탐색 50% / 검증 25% / 봉인 holdout 25%** — 경계 고정(데이터 열람 전, 근거 `research/facts_okx.md`):
  - 주 유니버스: BTC·ETH·SOL·SUI·XRP (SUI 시작 2023-05-05 → 2023-06-01부터). HYPE(2025-02-21 시작)는 E8 견고성 전용.
  - 탐색 2023-06-01 ~ 2025-02-28 (51.2%) · 검증 2025-03-01 ~ 2025-12-31 (24.5%) · holdout 2026-01-01 ~ 2026-10-31 (24.4%)
  - **오염 공시**: holdout은 기존 ORTHO 라이브 결과(2026-06~11)를 이미 본 구간과 겹친다 → ORTHO 파생 가설에는 2026-11-04 이후 전진 Shadow가 진짜 holdout.
- 탐색 내부에서만 롤링 워크포워드(예: 6개월 학습 → 3개월 검증, 3개월씩 전진). 구간 대다수(≥2/3)에서 Net > 0 이어야 함.
- holdout 구간 캐시는 **별도 디렉터리**에 저장, 해시만 기록, 분석 스크립트는 기본적으로 경로를 거부(`--open-holdout` 플래그 + LEDGER 기록 필수).

### 5.5 파라미터 예산
- 가설당 튜닝 가능 파라미터 **≤ 5** (청산 배리어·보유시간 포함). 고정 상수(수수료 등)는 미산입하되 목록화.
- 추가하려면 기존 하나 제거. 카운트는 `02` 카탈로그 표에 고정.

### 5.6 다수 변형 실험의 다중검정 구조
E-시리즈는 변형이 수십 개 나온다. 전부 Bonferroni로 묶으면 아무것도 통과 못 하고, 보정 없이 고르면 과적합이다. 그래서 **2층 구조**로 한다.

| 층 | 대상 | 보정 | 의미 |
|---|---|---|---|
| 1층 (탐색 구간) | 모든 E-실험 변형 | **Benjamini–Hochberg FDR 10%** | "검증에 올릴 가치가 있는가" 선별만. 채택 아님 |
| 2층 (검증 구간) | 4.5.2 최종 구성 (트랙당 1개) | **Bonferroni α = 0.05 / (검증에 올린 구성 수)** | 실제 채택 판정 |

추가 과적합 지표 (탐색 구간에서 산출, 보고서 필수):
- **PBO (Probability of Backtest Overfitting, CSCV 방식 — Bailey·Borwein·López de Prado·Zhu 2015)**: 시도한 모든 구성 행렬로 계산. **PBO > 0.5 이면 해당 트랙 기각.**
- **Deflated Sharpe Ratio (Bailey·López de Prado 2014)**: 시도 횟수·왜도·첨도 반영. DSR < 0.95 이면 경고.
- **탐색–검증 격차**: 탐색 Net R 대비 검증 Net R 감소율. 50% 넘게 줄면 과적합 경고.
