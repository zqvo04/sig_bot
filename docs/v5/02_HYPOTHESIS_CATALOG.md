### 2.3 검정력 · MDE 공식 [유도]
- MDE μ* = (z_{1−α/2} + z_{0.8}) · σ / √(n/DE). z_{0.8}=0.842, z_{0.975}=1.960, z_{0.9875}=2.241, z_{0.9975}=2.807.
- **σ = 1.24R** [인용 V4 실측]. 정당화: X0는 −1R/+1.5R 이진 + 시간청산. 이진만이면 σ=2.5·√(p(1−p)), p≈0.40(손익분기) → 1.22R; 시간청산이 σ를 줄이므로 1.24는 보수적 상한. **σ는 X0 기준으로 고정** — 청산을 바꿔 σ를 낮춰 R-단위 MDE 규칙을 우회하는 것을 금지.
- DE(설계효과) = 1.5 [가정]: 크립토 동조화로 같은 날 5심볼 신호가 독립 아님. 명목 n 기준 MDE는 **하한**.
- **분류 규칙 [인용 §5.2]: 탐색 구간 예상 n 기준 MDE(α=0.05) > 0.10R → "측정 불가"** (실험 안 함, 장부 기록). ※ 마스터 플랜 Phase 2 문단의 "MDE > 0.10R 인 가설만 실험 대상" 문구는 §5.2와 반대 — 오기로 보고 §5.2를 따름(결정 D5).

### 2.4 빈도 a-priori 공식 [유도 — 데이터 아님, ±2× 불확실]
사건률 r(봉당) → OPEN 차단 후 유효율 r_eff = r / (1 + r·H̄), H̄ = 평균 보유 7봉. 일 빈도 = r_eff × 봉/일. n = 5심볼 × 일수 × 일빈도.

## 3. 대조군 (파라미터 고정, 튜닝 없음, 장부 미산입)

### C0 — 무작위 진입 대조군 (가설마다 별도 생성)
| 요소 | 정의 |
|---|---|
| 입력 | 가설의 거래 목록에서 **(심볼, 월) 셀별 거래 수 N_sm**과 진입 TF만 사용 (결과 R은 사용하지 않음) |
| 시점 | 셀 내 적격 봉(지표 워밍업 이후, 엠바고 충족) 시가에서 균등 추출. 추출 → X0로 청산 시각까지 시뮬 → 구간 [진입, 청산]이 같은 심볼의 기배치 구간과 겹치면 기각·재추출(최대 1,000회). 미충족 시 부족 수 기록 |
| 방향 | **C0**: Bernoulli(0.5). **C0-β(필수 병기)**: 가설의 (심볼, 월) 롱 비율로 Bernoulli → 2023–24 상승 드리프트가 롱 편향 가설을 공짜로 돕는 효과 제거 |
| 청산·비용 | 가설과 **동일** 청산 규칙(ATR 배수는 무작위 진입 시점 ATR로 계산)·동일 시나리오·동일 펀딩 |
| 시드 | 0..199 (numpy PCG64), 시드별 Net R 평균 → 200개 귀무분포 |
| 판정 | 가설 Net 평균 > C0 **및** C0-β 분포 95백분위(190번째 순위). 200시드는 ~99.5백분위까지만 해상 → Bonferroni 수준 α<0.01은 C0 분포 정규근사(평균·SD)로 산출, 둘 다 보고 |

### C1 — 단순 추세추종 (Donchian 20)
- 규칙: 진입 TF에서 close_t > max(high_{t−20..t−1}) → 롱 / close_t < min(low_{t−20..t−1}) → 숏(미러). 청산 X0. N=20 고정(Turtle System 1 원형, 데이터 무관).
- 경제적 근거: 시계열 모멘텀(Moskowitz·Ooi·Pedersen 2012), 크립토 모멘텀(Liu·Tsyvinski 2021) — 정보 확산 지연·군집 추종. 지불자: 늦게 반응하는 역추세 유동성 공급자.
- 사용: H1·H4는 같은 TF의 C1보다 나아야 함("눌림목 논리"가 단순 돌파 대비 부가가치가 있는가).

### C2 — 단순 평균회귀 (Bollinger 20, 2σ)
- 규칙: close_t < SMA20 − 2·SD20 → 롱 / > SMA20 + 2·SD20 → 숏(미러). 청산 X0. (20, 2) 고정(관용 기본값).
- 경제적 근거: 단기 가격압력 반전·유동성 공급 보상(Lehmann 1990, Nagel 2012). 지불자: 즉시성을 사는 급한 매도/매수자.
- 사용: H2의 신호원(동일 신호에 체결 방식만 변경) + 모든 가설의 같은 TF 비교 기준.

## 8. 이 설계로 알 수 없는 것

1. **빈도·stop% 가정 오차**: 모든 n·MDE·cost_R은 a-priori(±2×). 실측 n이 절반이면 H1 MDE 0.068→0.096(√2배), 경계에 근접.
2. **검증 구간 검정력 부족**: H1 검증 MDE 0.108R — 0.10R 안팎의 진짜 엣지는 검증에서 놓칠 수 있다(FN). 놓침과 무엣지를 구분 불가.
3. **0.05R급 엣지**: 어떤 가설로도 측정 불가(§5.2: n≈4,800+ 필요). H2만 근접(0.048, DE 미반영).
4. **메이커 체결 현실성**: 캔들은 큐 위치·부분체결·호가 취소를 모른다. H2 결론은 6c 실체결 실측 전까지 조건부. 과거 스프레드·깊이 이력 없음(facts §4).
5. **비정상성**: 탐색(2023-06~2025-02)은 대체로 상승장. C0-β로 드리프트는 보정하나 레짐 회전 자체는 보정 불가. WF 폴드 n≈375(H1)는 폴드별 SE≈0.064R로 폴드 단위 판정은 거칠다.
6. **holdout 오염**: ORTHO 파생 구성은 holdout이 부분 오염 → 진짜 검증은 2026-11-04 이후 전진 Shadow(수개월 필요).
7. **펀딩·미시구조 알파**: 과거 데이터 부재로 H3·OBI·taker·LS 가설은 백테스트 불가. 전진 측정만.
8. **V4 완전 재현 불가**: V4의 `context_veto`(LS·taker)는 과거 데이터 없음 → 과거 구간 V4 리플레이 불가, H5는 로그된 실진입(2026)으로만.
9. **비용 시나리오**: 요율 미검증, 펀딩을 항상 지불로 가정(B) — 실제 펀딩 부호는 전략 방향과 상관될 수 있어 B가 과대/과소 모두 가능.
10. **동시 다중 비교의 잔여 위험**: BH-FDR·PBO·DSR을 써도 연구자 자유도(이 카탈로그의 가설 선택 자체)는 보정 밖.
